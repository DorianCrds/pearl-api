# 🧩 Pearl API

RESTful API for Pearl, a full-stack inventory and sales management solution for bead workshops.

---

## 🚀 Project Overview

This project is part of a full-stack suite including:
- `pearl-api` (backend REST API)
- `pearl-web` (web client with Next.js)
- `pearl-desktop` (desktop client with Python/PySide6)
- `pearl-mobile` (mobile client with React Native)

The goal of this project is to demonstrate a professional, maintainable, and complete full-stack solution for a small business workflow.

---

## 🛠️ Tech Stack

- Node.js
- TypeScript
- Express
- PostgreSQL (planned)
- Prisma (planned)

## 🏁 Getting Started
1. Install dependencies
```text
npm install
```
2. Run development server
```text
npm run dev
```
- Server will run at `http://localhost:4000`
- Example route : GET /hello -> returns a JSON message
